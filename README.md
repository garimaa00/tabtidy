# TabTidy

A simple Django web application that helps users organize saved
websites, reduce browser tab clutter, and track their exploration progress.

## Features

- Save website links with titles, notes, and categories
- Edit and delete saved links
- Mark important links as favourites
- Pin important links for quick access
- Search by title, URL, or note
- Filter by category and exploration status
- Track saved, explored, and pending links
- Dark/light mode toggle
- Responsive dashboard using Bootstrap 5
- Form validation using Django ModelForms
- Automated tests for core functionality

## Tech Stack

- Python
- Django
- SQLite
- HTML
- Bootstrap 5
- CSS
